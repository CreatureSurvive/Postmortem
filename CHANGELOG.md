# Changelog

## 1.0.0

- Initial release: typed parsing of MetricKit diagnostic and metric payloads (tested against
  JSON generated by MetricKit itself), a nesting-unlimited JSON parser for deep stacks, crash
  explanations, on-device symbolication with Swift demangling, text reports and `atos` scripts,
  `ReportStore` persistence with deduplication and retention, `PostmortemCollector`, and
  SwiftUI viewers.
